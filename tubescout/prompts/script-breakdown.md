# Script breakdown prompt: learn from a video that went viral

Get transcripts first: `python tubescout.py transcripts @SomeChannel --top 3`. This must be
run on your own computer, because YouTube blocks transcript downloads from cloud servers.
Paste one transcript under the line below.

---

This is the transcript of a YouTube video that got {VIEWS} views, which is {N}x its
channel's normal views. Break down why it works so I can reuse the structure, not the content.

1. **Hook (first 60 s).** Quote it. What question does it open? What specific facts does it
   use? How many seconds pass before the first number?
2. **Beat map.** List every section with its timestamp, its job (rise, turn, mini-story,
   fairness check, today, lesson) and the line that moves the viewer into the next section.
3. **The one-sentence thesis** that the whole video proves.
4. **Retention devices.** List every open loop, reversal, "but then…", vivid image and payoff
   number, with timestamps.
5. **Weak spots.** Which 30-second stretches drag?
6. **Reusable template.** Rewrite the structure as a fill-in-the-blanks outline I can use for
   a different subject.
